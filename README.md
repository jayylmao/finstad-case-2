# FINSTAD Case Study 2

A case study in which we create a consultation report on a portfolio of assets for our Advanced Statistics and Multivariate Research Techniques course.

## Requirements
- R
- R Studio

## Running the project
1. Clone the repository with `git clone https://github.com/jayylmao/finstad-case-2.git`.
2. Open R Studio.
3. Go to File > Open Project and open `finstad-case-2.Rproj`.
