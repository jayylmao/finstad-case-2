Many PSE stocks are no longer offered on Yahoo! Finance, so we use another free alternative called PSE Edge.

pse_pull <- function(cmpy_id, security_id, start = DATE_FROM_MDY, end = DATE_TO_MDY) {
  resp <- POST("https://edge.pse.com.ph/common/DisclosureCht.ax",
               body = list(cmpy_id = cmpy_id, security_id = security_id,
                           startDate = start, endDate = end),   # MM-DD-YYYY
               encode = "json",
               add_headers(
                 `X-Requested-With` = "XMLHttpRequest",
                 Referer = "https://edge.pse.com.ph/companyPage/stockData.do",
                 Origin = "https://edge.pse.com.ph",
                 Accept = "application/json, text/javascript, */*; q=0.01"))
  df <- fromJSON(content(resp, "text", encoding = "UTF-8"))$chartData
  df$date <- as.Date(df$CHART_DATE, format = "%b %d, %Y 00:00:00")
  df <- distinct(df, date, .keep_all = TRUE)
  df[order(df$date), c("date", "CLOSE")]
}

yahoo_pull <- function(sym, start = DATE_FROM, end = DATE_TO) {
  tq_get(sym, from = start, to = end) |>
    transmute(date = as.Date(date), !!sym := round(adjusted, 4))
}

We then clean the Treasury bill rates by dropping the blank months and computing the annual and daily risk-free rate.

tbill91_pct <- na.omit(tbill91)                # drops blank / no-auction months
rf_annual <- mean(tbill91_pct) / 100           # ~4% expected
rf_daily  <- (1 + rf_annual)^(1 / 252) - 1     # use in Sharpe / frontier

Exploratory Financial Analysis

First we compute for daily log returns to get a simple overview of each asset’s performance.

prices_php <- prices_php |>

Then present the findings in a table for easier understanding.

rets_wide <- prices_php |> select(date, ends_with("_return")) |> na.omit()

findings_summary <- rets_wide |>
  pivot_longer(-date, names_to = "asset", values_to = "ret") |>
  group_by(asset) |>
  summarise(
    `Mean Daily Ret (%)` = mean(ret, na.rm = TRUE) * 100,
    `SD Daily Ret (%)`   = sd(ret, na.rm = TRUE) * 100,
    `Ann. Ret (%)`       = mean(ret, na.rm = TRUE) * 252 * 100,
    `Ann. Vol (%)`       = sd(ret, na.rm = TRUE) * sqrt(252) * 100,
    Sharpe               = (mean(ret, na.rm = TRUE) * 252 - rf_annual) /
                           (sd(ret, na.rm = TRUE) * sqrt(252)),
    `Max Drawdown (%)` = { r <- ret[!is.na(ret)];
                       min(cumprod(1 + r) / cummax(cumprod(1 + r)) - 1) * 100 }
  ) |>
  ungroup()

To see the effects of optimization on our portfolio, we create a baseline of a a simple equal weighted portfolio, with and without re-balancing. This baseline gives us something to compare our optimized portfolios against.

portfolio_growth <- function(weights, ret_df = ret_data, rebalance = FALSE) {
  dates <- ret_df$date
  rets <- as.matrix(select(ret_df, ends_with("_return")))

  if (!rebalance) {
    asset_growth <- apply(rets, 2, function(r) cumprod(1 + r))
    port_value <- as.numeric(asset_growth %*% weights)
  } else {
    month_id <- format(dates, "%Y-%m")
    port_value <- numeric(length(dates))
    value <- 1
    holdings <- value * weights

    for (i in seq_along(dates)) {
      if (i > 1 && month_id[i] != month_id[i - 1]) {
        holdings <- value * weights 
      }
      holdings <- holdings * (1 + rets[i, ])
      value <- sum(holdings)
      port_value[i] <- value
    }
  }

  tibble(date = dates, value = port_value)
}

We re-balance because prices move and starts pulling the actual portfolio away from that optimum. Over time, some assets grow faster than others which can shift the target mix and exposes the assets to more risk than planned.

eq_weights <- rep(1 / n_assets, n_assets)

eq_no_rebal <- portfolio_growth(eq_weights, rebalance = FALSE) |> mutate(portfolio = "Equal Weight (No Rebalance)")
eq_rebal <- portfolio_growth(eq_weights, rebalance = TRUE)  |> mutate(portfolio = "Equal Weight (Monthly Rebalance)")

Lastly, we initialize equal weighing among the assets and call portfolio_growth() to create paths with and without monthly rebalancing.

Portfolio Optimization

With the return matrix and baseline established, we now solve for the three portfolios, the Efficient Frontier, the Global Minimum Variance (GMV) Portfolio, and the Maximum Sharpe Portfolio. We use the quadprog (quadratic programming) library to help with portfolio optimization. In general, these 3 techniques or theories all aim to achieve a singular goal, that being how to best balance or optimize the ratio of returns given risks in its own way.

Efficient Frontier

The efficient frontier is a core concept in Modern Portfolio Theory (MPT) introduced by Harry Markowitz in 1952. It is a curved line on a graph that shows the best investment portfolios, these portfolios give the highest expected return for a set level of risk, or the lowest risk for a set level of return.

We trace the frontier by minimizing variance for a grid of target returns spanning the achievable range.

Dmat <- 2 * Sigma
dvec <- rep(0, n_assets)
target_rets <- seq(min(mu), max(mu), length.out = 100)

eff_frontier <- map_dfr(target_rets, function(tr) {
  Amat_ef <- cbind(rep(1, n_assets), mu, diag(n_assets))
  bvec_ef <- c(1, tr, rep(0, n_assets))

  sol <- tryCatch(solve.QP(Dmat, dvec, Amat_ef, bvec_ef, meq = 2),
                   error = function(e) NULL)
  if (is.null(sol)) return(NULL)

  w <- sol$solution
  tibble(
    target_ret = tr,
    ret = sum(w * mu),
    vol = as.numeric(sqrt(t(w) %*% Sigma %*% w)),
    sharpe = (sum(w * mu) - rf_annual) / as.numeric(sqrt(t(w) %*% Sigma %*% w)),
    weights = list(setNames(w, assets))
  )
})

Global Minimum Variance Portfolio

A Global Minimum Variance (GMV) Portfolio is a specialized asset mix built from a set of risky investments that achieves the lowest possible total risk or price volatility (variance). It sits at the absolute leftmost point of the efficient frontier curve in MPT.

The GMV portfolio minimizes w'Σw subject to weights summing to 1.

Amat <- cbind(rep(1, n_assets), diag(n_assets))   # sum(w) = 1, w_i >= 0
bvec <- c(1, rep(0, n_assets))

gmv_sol <- solve.QP(Dmat, dvec, Amat, bvec, meq = 1)
gmv_weights <- setNames(gmv_sol$solution, assets)

gmv_ret <- sum(gmv_weights * mu)
gmv_vol <- as.numeric(sqrt(t(gmv_weights) %*% Sigma %*% gmv_weights))

set.seed(RANDOM_SEED)
n_sim_val <- 5000

simulate_portfolio_var <- function(port_ret, n_sim = n_sim_val, conf = conf_level) {
  mu_p <- mean(port_ret, na.rm = TRUE)
  sigma_p <- sd(port_ret, na.rm = TRUE)

  sim_returns <- rnorm(n_sim, mean = mu_p, sd = sigma_p)

  tibble(
    VaR = -quantile(sim_returns, probs = 1 - conf),
    ES = -mean(sim_returns[sim_returns <= quantile(sim_returns, probs = 1 - conf)])
  )
}
